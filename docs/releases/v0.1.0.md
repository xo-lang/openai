# v0.1.0

The first release of OpenAI's API client for Xo: `github.com/xo-lang/openai`
and `github.com/xo-lang/openai/azure`, tagged v0.1.0 at one commit.
Ported from openai-go v3.98.0 (Apache License 2.0, Copyright 2026
OpenAI). Requires Xo 0.46.0 or later.

A community library for the Xo language. Not affiliated with or
endorsed by OpenAI or Microsoft.

## What is in it

The surface Azure OpenAI uses: every client call in the examples of Go's
`azopenai` v0.9.0.

- The client: options, Go's retry rules, headers and errors.
- Chat completions (`chat_completion`, `chat_completion_stream`, the
  accumulator), the Responses API (`response`, `response_stream`,
  `delete_response`), embeddings, images (`generate_images`,
  `edit_images`), audio (`transcribe`, `translate`, `speech`) and legacy
  completions (`completion`, `completion_stream`).
- `azure`: Azure OpenAI endpoints (deployment routing for JSON and
  multipart routes, `api-version`), an API key or any azcore
  TokenCredential, the plain http rule.

Every call is checked against openai-go itself: a Go program runs it
against a local fake, and the Xo tests replay the same calls request by
request. No test calls a real endpoint.

## Install

```
xo get github.com/xo-lang/openai@v0.1.0 github.com/xo-lang/openai/azure@v0.1.0
```
