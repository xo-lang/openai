# Changelog

## v0.1.0 (2026-11-11)

The first release: the surface Azure OpenAI uses, ported from openai-go
v3.98.0 (README.md, "Scope of v0.1.0"): the client with Go's retries and
errors, chat completions and their stream, the Responses API (create,
stream, delete), embeddings, images (generate, edit), audio (transcribe,
translate, speech), legacy completions, and the `azure` module.
Requires Xo 0.46.0.
